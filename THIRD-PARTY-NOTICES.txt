Browser packages include the same library source and license, plus a standalone
relink kit in share/restunts/wasm-relink/. It contains the application and SDL
object/archive files, enhanced artwork, HTML shell, and build instructions needed
to relink the application with a modified Nuked library using the recorded
Emscripten SDK. No original game data is included or needed to relink. Keep the
complete kit with a redistributed browser package, even though only the HTML is
needed to run it. The own-use modification and debugging permissions above also
