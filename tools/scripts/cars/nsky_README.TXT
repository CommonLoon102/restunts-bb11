*** Nissan Skyline R32 GT-R ***
	for Stunts 1.1 - by Duplode

General info: 
This project started long ago out of the challenge of modeling a real world car
in Stunts as accurately as possible. That desire was matched by some demand
for slow (or rather, not so fast) custom cars and by my endless appreciation
of the Gran Turismo series, so I selected the legendary R32 GT-R to put the
plan into practice - a very appropriate choice, considering its release in
1989 puts it into the same timeframe as the other Stunts cars. Several months
went by, many details of CAR*.RES edition were brought into light and a
full-fledged edition of Stunts graphics became a reality. The GT-R model
slowly evolved, and eventually (with a useful push given by the deadline set
by Zak's design contest... =D) reached what is likely to become its definitive
form. The final product is a Stunts car occupying a niche close to Acura NSX
and Corvette ZR1 - as the real car probably would - but without powergear.
Additionally, some measures were taken to make the handling more enjoyable
than that of its direct competitors without making it needlessly easy.

Usage and distribution:
By the community, for the community. Feel free to make use of these files and
redistribute them as you wish. I only ask that, in case the car is made
available publicly for download, this readme gets bundled together with the
files.

Installation:
Extract all files (CARNSKY.RES, STDANSKY.VSH, STDBNSKY.VSH and STNSKY.3SH) to
your Stunts 1.1 folder. Note that due to graphic file format
incompatibilities the car won't load properly on 1.0 versions of the game (you
might even try to use CARNSKY.RES with a different set of graphic files, but
even the car performance is not guaranteed to remain the same).

Features:
- Torque curve and gear ratios proportional to the real car specs;
- Performance matches to a large extent available data for the GT-R, sourced
both from actual performance tests and Gran Turismo 2 runs;
- 3D models based on Skyline blueprints;
- Heavily customized dashboard layout built from modified NSX "components";
- Accurate analog dashboard meters.

Available colours:
- Blue
- Red
- Yellow
- Silver
- Purple
- Grey
- Copper

Performance data:
- 0-60mph  : 4.8s
- 0-100mph : 12.1s
- Quarter mile: 13.3s
- Top speed (straight line): 173mph
- Top speed (overall): 199mph 

Resources used during design:
- stressed (dstien's resource file editor for Stunts,
stuntstools.googlecode.com)
- GIMP (Image editor, www.gimp.org)
- Blueprints for R32 Skyline available at carblueprints.narod.ru
- Engauge Digitizer (Used for grabbing coordinates from the blueprints,
digitizer.sourceforge.net)
- Anim8or v0.97 (Easy-to-learn 3D modeling software, www.anim8or.com)
- CarBlaster (Mark Nailwood's CAR*.RES editor, available from zak.stunts.hu
in "Downloads" section)
